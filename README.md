CONVERSOR PARA MARKDOWN
Converte PDF, imagens com texto (OCR) e Word .docx em Markdown.
Tudo roda no navegador; nenhum arquivo e enviado para a internet.

USAR NESTE COMPUTADOR
  Clique duas vezes em "Abrir conversor.bat" (precisa do Python).
  Obs.: abrir o index.html direto com dois cliques NAO funciona.

PUBLICAR NA INTERNET (gratis, qualquer pessoa abre pelo link)
  Opcao 1 - Netlify Drop:
    1. Acesse https://app.netlify.com/drop e crie/entre na sua conta.
    2. Arraste ESTA PASTA inteira para a pagina.
    3. Pronto: o Netlify da um link publico.
  Opcao 2 - GitHub Pages:
    1. Crie uma conta em https://github.com e um repositorio publico.
    2. Envie todos os arquivos desta pasta (Add file > Upload files).
    3. Settings > Pages > Branch: main / root > Save.
    4. O link aparece em alguns minutos: https://SEU-USUARIO.github.io/NOME-DO-REPO/

Arquivos: index.html (a pagina) e vendor/ (bibliotecas: pdf.js, Tesseract OCR, mammoth, turndown).
